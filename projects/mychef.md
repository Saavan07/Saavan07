# myChef

A Spring 2026 CS 222 team project at the University of Illinois Urbana-Champaign, built by Saavan Kiran, Ayush Chandra, Sam Tewari, and Tanish Mittal.

The web application connects a vanilla JavaScript frontend to an Express API and MySQL. Implemented flows include accounts, dietary settings, pantry items, stored recipes, favorites, seven-entry meal plans, meal swaps, aggregated shopping lists, nearby grocery search, and store reviews. Its planner selects stored recipes using preferences, pantry overlap, favorites, and repetition penalties.

Saavan's recorded work includes frontend prototyping and shopping-list fixes spanning ingredient matching, quantities, manual items, and UI presentation. The team shared design, debugging, and integration work; exclusive versus shared responsibilities are still being refined.

This is a course prototype. Its inherited account handling and dietary logic require hardening before real-user deployment. Social meal sharing, AI recipe assistance, voice cooking guidance, and a native mobile release are future directions.

The [personal repository](https://github.com/Saavan07/myChef) contains the team's source, cleaned history, setup instructions, a local database schema, a screenshot of the actual running app, and verification results. The original team repository is preserved. This case study does not link to a production deployment.
